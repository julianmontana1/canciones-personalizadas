Bitácora de Proyecto: SongCraft AI

Generador comercial de canciones personalizadas a medida utilizando Inteligencia Artificial (ElevenLabs Music API), control de códigos, transcripción por voz y auditoría centralizada.

Autor: Julián Montaña • Fecha: Septiembre 2026 • Repositorio: github.com/julianmontana1/canciones-personalizadas

📌 1. Visión y Pilares del Sistema

🎧 Vista Comercial Usuario

Creación rápida sin requerir API Key. Incluye 13 géneros musicales, demos de estudio reales de 10s, asistente de dictado por voz y descarga directa en MP3.

🛡️ Superadmin & Auditoría

Registro en tiempo real de la IP del cliente, fecha y hora exacta, ID de ElevenLabs, reproductor en línea en la tabla y almacenamiento del archivo MP3 en el servidor.

🔑 Sistema de Códigos

Control comercial por cuota (1 canción, 5 canciones o ilimitado). Historial aislado donde el usuario solo ve sus canciones creadas con su código.

⏱️ 2. Línea de Tiempo y Fases Desarrolladas

Fase 1: Creación del MVP y Arquitectura Cliente-Servidor
Configuración inicial con React 19, Vite y Tailwind CSS v4. Implementación del backend en Express para resolver llamadas a ElevenLabs (`POST /v1/music/compose`), capturar IP del cliente y almacenar los archivos de audio en disco local.
Fase 2: Separación de Vistas (Usuario vs. Superadmin)
  • Vista de Usuario: Experiencia enfocada en la creación y descarga directa, completamente limpia de historiales externos.
  • Vista de Superadmin: Acceso protegido con clave (admin123), tabla con IP, fecha, hora, ID de ElevenLabs, reproductor y opción de borrado.
Fase 3: Dictado por Voz, Códigos de Acceso y Persistencia
  • Reconocimiento de Voz: Asistente inteligente usando Web Speech API que detecta destinatario, estilo y recuerdos de forma hablada.
  • Gestión de Códigos: Validación de saldo con 3 códigos creados (TEST-1SONG-7A9B, VIP-5SONGS-K3M8 y MASTER-UNLIMITED-PRO).
  • Solución a Recargas: Persistencia en localStorage y botón de descarga directa por Blob URL.
  • API Key Transparente: Configuración central en la pestaña de ajustes de Superadmin.
Fase 4: Muestras de Estudio Reales y Nuevas Categorías
Sustitución de los sintetizadores robóticos por 13 grabaciones reales de estudio en MP3 con instrumentos auténticos. Incorporación de los géneros: Música Infantil, Canción de Dormir / Nana, Salsa Brava, Mariachi y Banda Sinaloense.
Fase 5: Despliegue en GitHub y Protección de Secretos
Publicación exitosa en GitHub con configuración rigurosa en .gitignore para proteger la API Key real y archivos de clientes, dejando plantillas limpias para nuevos entornos.

🛡️ Clave de Superadmin

Contraseña predeterminada: admin123. Permite ingresar al panel de auditoría, revisar IPs, escuchar y descargar todos los MP3 generados, crear nuevos códigos y actualizar la API Key de ElevenLabs.

📡 5. Referencia de Endpoints Backend (Puerto 3001)

// Públicos:
GET  /api/health                    -> Verifica estado y hora del servidor
GET  /api/codes/validate?code=XYZ   -> Valida código de acceso y saldo restante
GET  /api/codes/my-songs?code=XYZ   -> Devuelve únicamente el historial del código
POST /api/generate                  -> Genera canción con ElevenLabs y guarda MP3
GET  /api/storage/songs/:filename   -> Streaming y descarga directa de audio MP3

// Privados (Superadmin con header x-admin-key):
POST   /api/admin/verify            -> Verifica contraseña de administrador
GET    /api/admin/history           -> Retorna auditoría con IP, fecha, ID y canciones
DELETE /api/admin/history/:id       -> Elimina registro y borra el archivo MP3
GET    /api/admin/codes             -> Lista todos los códigos de acceso activos
POST   /api/admin/codes             -> Crea nuevo código con límite personalizado
DELETE /api/admin/codes/:code       -> Elimina un código de acceso
GET    /api/admin/settings          -> Consulta estado de API Key (enmascarada)
POST   /api/admin/settings          -> Actualiza API Key o contraseña de Superadmin

🚀 Cómo Iniciar la Plataforma Localmente

Abre dos terminales en el directorio raíz del proyecto y ejecuta: 

# Terminal 1: Backend Express (Puerto 3001)
npm run server

# Terminal 2: Frontend Vite + React (Puerto 5173 / 5174)
npm run dev

Abre tu navegador en http://localhost:5173/
